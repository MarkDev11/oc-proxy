About

Thin OpenAI-compatible proxy for the opencode.ai free tier. Zero dependencies, Vercel-ready.

  • GET /v1/models — free models, fetched live from upstream (5 min cache)
  • POST /v1/chat/completions — OpenAI shape: messages, tools, tool_choice, stream
  • GET /api/health — deployment check

Source: github.com/MarkDev11/oc-proxy. Long requests close gracefully with finish_reason: "length" so agent loops can continue.
